# Voice Spoofing Detection

This project investigates the detection of synthetic and converted speech using a Light Convolutional Neural Network (LCNN) with Max-Feature-Map activations. The proposed system operates on spectral representations of audio signals and is evaluated on the Logical Access subset of the ASVspoof 2019 dataset.

**Results:** The model achieved an Equal Error Rate (EER) of **4.4735%** on the evaluation set.

**Technologies:** Python, PyTorch, Torchaudio, NumPy, Pandas, Weights & Biases.

**Dataset:** [ASVspoof 2019](https://www.kaggle.com/datasets/awsaf49/asvpoof-2019-dataset)

A detailed description of the methodology, model architecture, experimental setup, and results is provided in the accompanying **[Technical Report](Report.pdf)**.
